# HTML Portfolio Practice

This repository contains early HTML coursework completed while working through **Angela Yu's Web Development Bootcamp**. I keep it public as a learning archive showing my first work with page structure, links, images, semantic sections, and multi-page navigation.

> **Portfolio context:** This is intentionally a beginner HTML project, not a current flagship application. For more advanced work, see my [GitHub profile](https://github.com/avery-holmes) and my [SENG 505 Java Applications](https://github.com/avery-holmes/SENG505-Java-Applications) repository.

## What this project demonstrates

- basic HTML document structure
- headings, paragraphs, lists, and horizontal rules
- relative links between pages
- images and accessible `alt` text
- simple multi-page navigation
- semantic elements such as `header`, `main`, `section`, `nav`, and `footer`

## Why I keep this repository

This repo documents the early web-development portion of my transition into software engineering. I have deliberately kept the implementation simple rather than rewriting a beginner HTML exercise with technologies I learned later.

The repository has been lightly cleaned for portfolio use: broken links and tutorial TODO comments were removed, page structure was normalized, and personal contact details were minimized.
